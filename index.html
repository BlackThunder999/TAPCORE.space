📖 Как писать на РуКоде

        
      

      

        
В РуКоде не нужны точки с запятой и сложные скобки. Просто пиши команды с новой строки:

        

          пусть монеты = 0

          заголовок Моя игра

          текст [id: баланс] Монет: {монеты}

          кнопка Фармить -> монеты + 1; обновить баланс "Монет: {монеты}"; конфетти


          если монеты == 5 то

            уведомление Ты набрал 5 монет!

          конец
        

        
Фишки: используй {имя_переменной} прямо внутри любого текста, чтобы подставлять туда значения на лету. Через ; можно вешать сразу несколько действий на одну кнопку!
